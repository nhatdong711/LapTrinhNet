## CHỨC NĂNG ĐÃ THỰC HIỆN
- Validate: để trống/nhập chữ ở ô số → MessageBox cảnh báo; % giảm phải trong 0-100.
- Tổng tiền = (Đơn giá × Số lượng) × (100 − %Giảm) / 100, định dạng tiền Việt.
- TabIndex hợp lý: Đơn giá → Số lượng → % Giảm → Tính tiền → Làm mới; Enter = Tính tiền.
